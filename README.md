# Blablacar Clone MVP

Um MVP de marketplace de caronas inspirado no fluxo do BlaBlaCar, feito 100% em HTML, CSS e JavaScript puro, compatível com GitHub Pages. O projeto simula um app de carona com busca de viagens, listagem por cidades, cartões de viagem e uma página de motorista com WhatsApp. Também contempla o envio de encomendas e transporte de documentos para quem viaja e quer monetizar a rota.

Palavras‑chave para SEO: blablacar clone, MVP de caronas, marketplace de caronas, aplicativo de carona, caronas intermunicipais, envio de encomendas, transporte de documentos, site para caronas, app de viagens compartilhadas, GitHub Pages.

## 1. Visão geral do projeto

- Objetivo: entregar um MVP estático, rápido e editável, pronto para validação de mercado.
- Público: passageiros, motoristas e pessoas que precisam enviar encomendas ou documentos.
- Diferenciais: página de motorista com foto, carro, avaliações e contato direto via WhatsApp.

### Páginas principais

- index.html: landing page com destaques e CTA.
- buscar.html: resultados filtráveis por origem, destino, data, estado e cidade.
- cidades.html: listagem de estados e cidades atendidas.
- cidade-sp.html, cidade-rj.html, cidade-mg.html: páginas com viagens por cidade.
- cadastrar-viagem.html: formulário para motoristas.
- como-funciona.html: explicação do marketplace.
- sobre.html: quem somos e serviços oferecidos.
- motorista.html: perfil do motorista com contato e avaliações.

## 2. Para programadores

### Stack e arquitetura

- HTML5, CSS3 e JavaScript puro.
- Sem backend, sem build, sem dependências de servidor.
- Compatível com GitHub Pages.
- Dados fake centralizados em assets/js/app.js.

### Estrutura de pastas

- blablacar-clone-mvp/
  - assets/css: estilos base + personalizações em app.css
  - assets/js: lógica de dados e renderização em app.js
  - páginas HTML estáticas do MVP

### Como rodar localmente

1. Abra a pasta blablacar-clone-mvp em um servidor estático.
2. Exemplo em Python:

   python -m http.server 8001

3. Acesse no navegador:

   http://localhost:8001/blablacar-clone-mvp/

### Como publicar no GitHub Pages

1. Suba o projeto para um repositório no GitHub.
2. Ative o GitHub Pages apontando para a pasta raiz do projeto.
3. O site fica disponível em minutos no domínio do GitHub Pages.
